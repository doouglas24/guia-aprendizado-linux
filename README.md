# Fundamentos de linux para iniciantes

## Objetivo
Ensinar os conceito básicos do sistema operacional Linux, navegação no terminal e comandos essenciais para quem está começando.

## Público-alvo
Estudantes e iniciantes sem experiência prévia com Linux.

## Pré-requisitos
Um computador com sistema Linux ou máquina virtual/WSL.
Vontade de aprender a utilizar a linha de comando.

- docs/02-conceitos.md
- docs/03-exercicios.md
- docs/04-referencias.md
